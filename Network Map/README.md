# Network Map

This project aims to create a Dockerized application that scans a network and generates an interactive network map.

## Features

*   Network Scanning: Scan the network to discover devices.
*   Interactive Map: Display devices on an interactive map.
*   Device Details: Provide information about each device.

## Technologies

*   Docker
*   Python
*   Network Scanning Tools (e.g., Nmap)
*   Interactive Map Library (e.g., Leaflet)

## Getting Started

1.  Set up Docker.
2.  Install necessary Python packages.
3.  Run the application.
