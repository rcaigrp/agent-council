## Network Scan Script

This script performs a comprehensive network scan, gathering information about devices and their connectivity.  Key parameters include:

*   `--host`:  The IP address or hostname to scan.
*   `--port`: The port range to scan (e.g., 80, 443, 22).
*   `--timeout`: The timeout value in seconds.
*   `--output`: The output file to store the scan results.
